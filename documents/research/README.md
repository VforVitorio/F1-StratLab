# Research and design notes

This folder contains agent-assisted research, architecture proposals, and design records. The documents are working references, not proof that a feature shipped.

- Treat measured observations and code references as evidence only for the stated version and scope.
- Treat proposals and open questions as decisions still needing confirmation.
- Check the current issue and implementation before using an older design as a task list.
- Keep dates, sources, and limitations with the document when updating it.

The PITWALL documents cover separate stages: `PITWALL_REALISM_AND_TELEMETRY_SURFACE.md` records the earlier design, `PITWALL_V2_ARCHITECTURE.md` records the architecture decision, and `PITWALL_TRACES_SPACE_SPEC.md` specifies a later layout. The architecture document supersedes only sections 3–6 of the earlier design; its observability material remains relevant.
